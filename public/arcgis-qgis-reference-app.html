  1. Download the GeoJSON for your target FIPS code:
    curl "https://your-endpoint.com/arcgis-geojson?fips=13247&type=soil" -o rockdale_soils.geojson
  2. In QGIS, go to Layer → Add Layer → Add Vector Layer
  3. Set Source Type to GeoJSON and browse to your file
  4. Click Add — the layer appears in your project with EPSG:4326 (WGS 84)
  1. Right-click the soil layer → Properties → Symbology
  2. Choose Categorized and select hydrologicGroup as the value column
  3. Click Classify to generate color-coded soil groups (A, B, C, D)
  4. Use Joins to attach local parcel data by map unit key

API

Endpoint Reference

GET /arcgis-geojson?fips={fips_code}&type={soil|water|crop}

# Example: Rockdale County, GA soils
curl -s "https://your-endpoint.com/arcgis-geojson?fips=13247&type=soil" \
  | jq '.features[0].properties'

Returns RFC 7946 GeoJSON with FeatureCollection of soil map units. Each feature includes mukey, muname, hydrologicGroup, drainageClass, farmlandClass, and source coverage metadata.
