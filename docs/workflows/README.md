## How to Use These Guides

**Written instruction:** Follow the numbered steps in each workflow. Callouts marked 🎥 indicate ideal video pause/narration points.

**Video production:** Each workflow includes `[VIDEO NARRATION]` blocks with suggested script, on-screen annotations, and transition notes for recording walkthrough videos.

**Prerequisite chain:** Workflows 1 → 2 → 3 build on each other. Workflows 4–9 are independent and can be done in any order. Workflow 10 ties everything together for a complete season.
