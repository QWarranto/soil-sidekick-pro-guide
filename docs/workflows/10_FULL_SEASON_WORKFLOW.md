### During Planting
| Action | Frequency | Tool |
|--------|-----------|------|
| Monitor soil temperature and moisture | Daily | Sensors / Dashboard |
| Check frost risk alerts | Daily | Notifications |
| Track planting progress | Daily | Task Manager |
| Use offline AI for in-field questions | As needed | [Workflow 6](06_OFFLINE_AI.md) |

```
[VIDEO NARRATION]
"During planting, you're checking the dashboard daily. Soil temperature
and moisture tell you if conditions are right. If you're in the field

```

### Key Decision Points
| Signal | Action |
|--------|--------|
| Soil temp <50°F (corn) | Delay planting; monitor daily |
| Moisture >85% | Wait for drainage; check satellite moisture map |
| Frost alert | Activate frost protection plan (from Task Manager) |
| Sensor shows dry pocket | Irrigate that zone before planting |

## Phase 3: Growing Season (Weeks 4–16)

### Weekly Routine
| Day | Action | Tool |
|-----|--------|------|
| Monday | Review satellite NDVI for vegetation health | AlphaEarth / Field Mapping |
| Tuesday | Check sensor data trends (moisture, temp) | Dashboard |
| Wednesday | Scout fields guided by satellite stress zones | Offline AI for ID help |
| Thursday | Update task progress; log observations | Task Manager |
| Friday | Review environmental alerts and water quality | Water Quality |

## Phase 5: Post-Season Review (Weeks 20–24)

### Season Review Workflow

1. **Export all reports** — soil analyses, environmental assessments, VRT results.
2. **Calculate actual ROI:**
   - Input costs (actual vs. planned)
   - Yield results (actual vs. predicted)
   - VRT savings realized
   - Carbon credits generated
3. **Document lessons learned** in Task Manager completion notes.
4. **Plan improvements** for next season.
5. **Set up recurring tasks** for next year's critical activities.

```
[VIDEO NARRATION]
"The post-season review is where it all comes together. Export your
reports, calculate your actual ROI, and document what worked and what
didn't. Set up recurring tasks now so next year starts with a running
start instead of a scramble."
```

### Annual Metrics to Track

| Metric | Source | Goal |
|--------|--------|------|
| Soil organic matter trend | Soil Analysis (year-over-year) | Increase 0.1–0.2% annually |
| Input cost per acre | Cost Monitoring | Reduce 5–10% via VRT |
| Yield per acre | Yield tracking | Increase or maintain |
| Water quality grades | Water Quality | Maintain A/B grades |
| Carbon credits earned | Carbon Credit Dashboard | Increase with practices |
| Environmental risk score | AlphaEarth | Reduce over time |
